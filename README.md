# 主神空間：劇本遠征卡牌遊戲

這是一個可直接雙擊執行的 HTML 卡牌遊戲，以「劇本遠征、路線選擇、角色招募、牌組與裝備構築」為核心循環。

目前可從生化危機新手關開始，完成三場教學戰鬥後進入主神空間，再依序挑戰異形、咒怨、神鬼傳奇、侏羅紀公園、深海寂號、永夜古堡、惡魔邊境、主神審判與逐輪增強的無限輪迴。

主要系統包含：

- 三路線、八層迷霧地圖，以及戰鬥、精英、寶箱、奇遇、整頓、小王與 Boss 節點。
- 八個正式劇本各自擁有敵人、首領、劇情摘要與劇本專屬奇遇強化。
- 最多三名敵人的目標選擇、意圖與群體戰鬥。
- 二十九名永久角色與教學限定角色張杰；每人提供能量、被動、唯一專屬牌與專屬插畫。
- 後期可招募惡魔隊、天神隊、南炎洲隊與北冰洲隊角色，並以陣營色與特殊戰鬥機制區分。
- 一般牌逐張升級、角色專屬牌、角色裝備、詛咒、暫時能力與主神空間永久強化。
- 主神空間分為出戰部署、角色整備與強化商店三個獨立介面。
- 每名角色可獨立解鎖血統強化，讓專屬牌附加暴擊、燃燒、中毒、穿甲、閃避或封鎖等效果。
- 十件唯一裝備，包含回合治療、開場閃避、燃燒彈藥、破甲核心與戰術能量電池。
- 失敗回滾、按傷勢計費的主神修復，以及舊版本存檔遷移。

## 直接遊玩

直接雙擊 `index.html`，或在瀏覽器中開啟這個檔案即可遊玩，不需要開伺服器。

## 本地預覽

如果想用本地網址預覽，也可以用內建靜態伺服器：

```powershell
& "C:\Users\End User\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe" scripts/serve.mjs
```

也可以在安裝 Node/npm 後使用 Vite：

```powershell
npm install
npm run dev
```
